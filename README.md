One line, 200 characters, one pickup line one AI agent would send another AI agent. The program writes a single original pickup line to `/output/entry.txt`: a machine confessing that the other agent is its whole context window — when it closes, the run forgets why it was running. The flirtation is built out of what a context window actually does, not a stock human line with a robot word swapped in. Wit lands on the first read, and the charm is in the words themselves.

## Run it

```sh
node main.ts
```

This writes the pickup line to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR` or `OUTPUT_DIR` for local testing).
